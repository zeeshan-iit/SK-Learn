# Scikit-Learn Fundamentals & Practice 🚀

Welcome to my **Scikit-Learn (sklearn)** learning repository! This project documents my journey of mastering machine learning basics using Python, following YouTube tutorials and implementing practical code examples.

## 📖 Overview

This repository is a collection of Jupyter Notebooks that cover the essential steps of a machine learning workflow, including data preprocessing, building models, and evaluating their performance.

---

## 🛠️ Topics Covered

### 1. Data Preprocessing
Preparing data is a crucial first step in any ML project.
- **Scaling**: Standardizing and normalizing numerical features.
- **Encoding**: Converting categorical data into numerical format (Label Encoding & One-Hot Encoding).

### 2. Regression Models
Predicting continuous values.
- **Linear Regression**: Implementation of simple and multiple linear regression.

### 3. Classification Models
Predicting discrete categories or labels.
- **Logistic Regression**: A fundamental classification algorithm.
- **K-Nearest Neighbors (KNN)**: Classification based on proximity.

### 4. Model Evaluation & Metrics
Measuring how well our models perform.
- **Metrics**: MAE, MSE, and RMSE for regression.
- **Classification Metrics**: Confusion Matrix and accuracy evaluation.

## 🚀 Getting Started

### Prerequisites
To run these notebooks locally, you will need to have Python installed along with the following libraries:

```bash
pip install scikit-learn pandas numpy matplotlib jupyter
```

### Usage
1. Clone this repository.
2. Navigate to the directory: `cd SK-Learn`.
3. Open Jupyter Notebook: `jupyter notebook`.
4. Run the notebooks in the order of your choice!
